SSIMF Converter

SSIMF (ScreenShot IMage Format) is a lossless image format built for screenshots. Drop a screenshot to see how small it gets, save it as SSIMF, or open an SSIMF file to view it. Everything runs in your browser; nothing is uploaded.

How it works

Four questions per pixel

first

Copy from earlier?

Screenshots repeat words, icons and table rows. SSIMF can say “copy the next 40 pixels from 3 rows up” in a few bits.

then

Same as a neighbour?

Most pixels match the one to the left or above. In flat areas this costs almost nothing.

then

A recent colour?

Text edges reuse a handful of blended colours. SSIMF keeps the last 32 new colours on hand.

last

Spell it out

Only new colours are written, predicted from the surrounding pixels so the difference is small.

Each answer is stored with an adaptive range coder that learns the odds as it goes, so common answers take a fraction of a bit.

Limits

What this prototype is not

  • No browser, phone or app can open .ssimf files yet. Only this page and the code that comes with it can.
  • It is lossless, so it is best on screenshots. For photos, JPG, lossy WebP or AVIF will be far smaller.
  • Opening an SSIMF file is slower than PNG or WebP (about 0.1 s in C, 0.2–0.5 s here, for a 3.4-megapixel screenshot).
  • The file format may still change, so treat version 1 files as test files.
  • Images with partly transparent pixels may change slightly when your browser reads them into the page. Screenshots are fully opaque, so this does not affect them.
